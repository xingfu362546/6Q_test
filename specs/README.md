## 交付标准

每个 spec 目录至少包含：

- `spec.md`：用户故事、验收场景、功能需求、成功标准
- `plan.md`：技术方案、目录、阶段、风险
- `tasks.md`：可勾选任务
- `data-model.md`：实体、字段、关系、状态机
- `contracts/api.md`：接口契约与原型替代
- `research.md`：源码分析、决策、未决问题
- `quickstart.md`：启动与验收路径
- `checklist.md`：交付检查

格式与注释规范见 [`../docs/CONVENTIONS.md`](../docs/CONVENTIONS.md)。
