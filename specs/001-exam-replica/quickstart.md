# Quickstart: 6Q 测评复刻 v2.0.0

## 1. 启动

在仓库根目录执行：

```bash
python -m http.server 8766
```

不要分别进入子目录启动，功能清单与两端页面之间有相对跳转。

## 2. 入口

| 入口 | 地址 |
| --- | --- |
| 项目入口 | `http://localhost:8766/` |
| 后台功能清单 | `http://localhost:8766/6Q_exam_battalion/index.html` |
| 后台复刻 | `http://localhost:8766/6Q_exam_battalion/replica.html?p=template-list` |
| H5 首页 | `http://localhost:8766/6Q_exam_h5/index.html` |

## 3. 后台验收路径

1. 模板列表 → 新增模板 → 填基础信息 → 切「题目」改分值 → 切「结果」改区间 → 确定。
2. 模板列表勾选一条 → 禁用 → 确认级联下架商品。
3. 商品列表 → 新增商品 → 添加模板 → 保存。
4. 测评主题 → 新增主题 → 添加商品 → 保存。
5. 维度管理 → 新增 → 添加指标 → 上移/下移 → 保存。
6. 分类管理 → 新增 → 勾选金刚区 → 保存。
7. 测评数据 → 切换明细/汇总 → 筛选 → 导出提示。
8. 任意页点红色序号 → 注释面板五段。

## 4. H5 验收路径

1. 首页 → 点左侧 AQ 分类 → 右侧只剩 AQ 商品；切换最新/热门/价格。
2. 点 AQ 卡片 → 详情 → 立即测试 → 测试须知。
3. 我已阅读 → 年龄页 → 输入 14 → 答题页。
4. 选中选项自动下一题；底部累计用时持续增加；最后一题提交。
5. 结果页 → 切换维度雷达/正态分布 → 查看整体解读、各类详解、建议、6Q 和谐指数。
6. 结果页 → 评分 + 反馈 → 提交。
7. 结果页分享 → 海报弹窗 → 下载 PNG。
8. 首页右上角我的测评 → 未完成/已完成 → 查看报告 / 再测一次。
9. 详情 → 立即测试 → 须知 → 订单确认 → 支付 → 余额抵扣。
10. 登录页 → 直接点登录（自动填测试账号）→ 返回。
11. 每页点红色序号 → 注释面板。

## 5. 复位数据

打开浏览器控制台：

```js
Object.keys(localStorage).filter(k => k.startsWith('exam_')).forEach(k => localStorage.removeItem(k));
location.reload();
```

## 6. 常见问题

**页面 404？**  
确认从仓库根启动服务，而不是从 `6Q_exam_battalion/` 或 `6Q_exam_h5/` 启动。

**注释不展开？**  
确认 URL 带 `?note=EX-xxx`，或点页面红点。

**答题记录没有了？**  
localStorage 被清理或换了浏览器；原型数据只存在本地。

**海报下载没反应？**  
浏览器可能拦截下载；允许下载后重试。
