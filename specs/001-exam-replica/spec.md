# Feature Specification: 6Q 测评复刻（后台 + H5）

**Feature Branch**: `001-exam-replica`  
**Version**: `v2.0.0`  
**Created**: 2026-11-12  
**Status**: Draft  
**Input**: 复刻 `sixQEducation-platform` 测评管理后台与 `exam2.0` 测评 H5，复用领袖营后台框架与注释规范。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 后台测评模板管理 (Priority: P1)

运营在后台维护测评模板：新建模板、配置基础信息、题目与报告结果，启用后供商品关联。

**Why this priority**: 模板是测评内容的核心，商品、答题、结果都依赖模板。

**Independent Test**: 打开 `replica.html?p=template-list`，新建模板并保存，列表出现新记录；打开详情能看到基础信息、题目与结果。

**Acceptance Scenarios**:

1. **Given** 模板列表，**When** 按分类/名称/状态筛选，**Then** 列表只显示匹配记录。
2. **Given** 禁用态模板，**When** 点修改，**Then** 进入编辑页；启用态不显示修改。
3. **Given** 模板编辑页，**When** 修改题目分值，**Then** 测评总分同步更新。
4. **Given** 模板禁用，**When** 确认禁用，**Then** 关联商品同步下架。

---

### User Story 2 - 后台商品与主题 (Priority: P1)

运营创建测评商品、关联模板、设置价格与展示到心画；主题把商品分组展示到 H5。

**Why this priority**: 商品是 H5 的入口，主题决定首页分组。

**Independent Test**: 打开 `replica.html?p=goods-list` 新增商品并关联模板；打开 `subject` 新增主题并关联商品。

**Acceptance Scenarios**:

1. **Given** 商品表单，**When** 未关联模板点确定，**Then** 提示至少关联一个模板。
2. **Given** 商品列表，**When** 切换「展示到心画」，**Then** 状态即时变化。
3. **Given** 主题表单，**When** 关联多个商品，**Then** 商品表按选择结果展示。

---

### User Story 3 - H5 测评主链路 (Priority: P1)

用户从首页选测评，查看详情，阅读须知，填年龄，完成答题，看到结果与海报。

**Why this priority**: 这是测评产品的核心用户价值。

**Independent Test**: 打开 `6Q_exam_h5/index.html`，进入 AQ 详情，立即测试，阅读须知，填年龄，答完 12 题，看到结果并打开海报。

**Acceptance Scenarios**:

1. **Given** H5 首页，**When** 点左侧 AQ 分类，**Then** 右侧只显示 AQ 商品。
2. **Given** 答案页，**When** 选中选项，**Then** 自动进入下一题；最后一题出现上一题/提交。
3. **Given** 答题页，**When** 停留，**Then** 底部累计用时持续增加。
4. **Given** 未选当前题点提交，**Then** 提示「请选择答案」。
5. **Given** 结果页，**When** 切换图表，**Then** 维度雷达与正态分布切换展示。
6. **Given** 结果页，**When** 打开海报，**Then** 可下载 PNG。

---

### User Story 4 - H5 记录、订单与登录 (Priority: P2)

用户查看我的测评、确认订单、选择支付方式、登录。

**Why this priority**: 承接复测、购买与账号体系。

**Independent Test**: 完成一次测评后进入我的测评，切到已完成能看到记录；从详情进入确认订单、支付页；从登录页登录后回上一页。

**Acceptance Scenarios**:

1. **Given** 已完成的测评，**When** 打开我的测评 → 已完成，**Then** 显示封面、名称、支付时间、订单号、价格与查看报告/再测一次。
2. **Given** 未完成的测评，**When** 打开我的测评 → 未完成，**Then** 显示开始测试入口。
3. **Given** 详情页，**When** 点立即测试，**Then** 进入须知；agedTag=true 时先填年龄。
4. **Given** 登录页，**When** 不填账号密码直接登录，**Then** 自动填测试账号并登录成功。
5. **Given** 支付页，**When** 勾选余额抵扣，**Then** 支付金额减 20。

---

### User Story 5 - 数据与运营查看 (Priority: P2)

运营查看测评反馈、预约留言与测评数据明细/汇总。

**Why this priority**: 支撑运营跟进与效果评估。

**Independent Test**: 打开 `replica.html?p=data` 切换两个页签，筛选与列正常；打开 `appraise` 与 `mental` 查看列表。

**Acceptance Scenarios**:

1. **Given** 测评数据，**When** 切换明细/汇总，**Then** 两个表格分别渲染。
2. **Given** 预约列表，**When** 点跟进并保存，**Then** 状态与备注更新。
3. **Given** 反馈列表，**When** 按星级筛选，**Then** 只显示对应星级。

---

### Edge Cases

- H5 中途退出：弹「退出后作答历史将不会保存」，确认后回详情。
- 未选当前题点提交：提示「请选择答案」，不提交。
- 模板被禁用：商品级联下架，H5 不再展示。
- 分类被禁用：模板与商品级联下架。
- 主题被禁用：H5 首页不展示该主题，商品不受影响。
- 收藏重复点击：切换状态，不产生重复记录。
- 结果页反馈：同一测评提交后锁定输入，按钮变已提交。
- 已购买过同一测评：详情点立即测试弹「去支付 / 查看报告」。
- 结果记录不存在：回退到 demo 记录，页面不白屏。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 后台 MUST 提供测评模板列表、筛选、启用/禁用、导入分数入口。
- **FR-002**: 后台 MUST 提供模板三段式编辑：基础信息、题目、报告结果。
- **FR-003**: 后台 MUST 在题目选项分值变化时实时累加测评总分。
- **FR-004**: 后台 MUST 在模板禁用时级联下架关联商品。
- **FR-005**: 后台 MUST 提供商品列表、新增/编辑、详情与二维码下载。
- **FR-006**: 后台 MUST 提供测评主题、分类、维度管理，并支持排序与启停。
- **FR-007**: 后台 MUST 提供测评介绍、反馈、预约留言、测评数据页面。
- **FR-008**: H5 MUST 提供 10 个源码路由页：首页 / 登录 / 详情 / 须知 / 年龄 / 答题 / 结果 / 我的测评 / 确认订单 / 支付。
- **FR-009**: H5 首页 MUST 支持左侧分类、右侧排序与空态。
- **FR-010**: H5 答题 MUST 支持单选、自动下一题、上一题/提交、累计用时与退出确认。
- **FR-011**: H5 结果 MUST 按模板开关展示总分、维度雷达、正态分布与 6Q 和谐指数。
- **FR-012**: H5 MUST 支持详情/结果海报、结果页反馈、我的测评、订单确认/支付与账号登录。
- **FR-013**: 全站 MUST 使用统一 `v2.0.0` 与五段式注释。
- **FR-014**: 功能清单 MUST 覆盖后台 18 条、H5 16 条，并可跳转原型展开注释。
- **FR-015**: 所有写操作 MUST 可回滚到初始 mock 数据（刷新页面恢复）。

### Key Entities

- **测评模板（Template）**: 标题、副标题、分类、维度模板、题目、结果区间、展示开关。
- **题目（Question）**: 题型、题干、关联维度、选项与分值。
- **结果（Result）**: 指数名称、区间、基础解读、维度解读、建议。
- **商品（Goods）**: 编号、名称、价格、模板、封面、上下架、展示到心画。
- **主题（Subject）**: 名称、封面、描述、排序、关联商品、状态。
- **分类（Category）**: 名称、图标、排序、金刚区、状态。
- **维度（Dimension）**: 模板名称、描述、指标行、状态。
- **测评记录（Record）**: 商品、得分、总分、区间、维度分、答案、时间、状态。
- **反馈（Feedback）**: 会员、模板、星级、内容、时间。
- **预约（Appointment）**: 昵称、称呼、类型、方向、手机、来源、跟进状态、备注。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 功能清单的每个链接都能打开对应原型，不出现 404。
- **SC-002**: 后台 9 个模块均能渲染列表或表单，控制台无 JS 报错。
- **SC-003**: H5 主链路可从首页走到海报页，答题进度可续答。
- **SC-004**: 每页红点能打开注释面板，注释包含五段。
- **SC-005**: 在 1366px 与 390px 宽度下无横向滚动，主要操作可点击。
- **SC-006**: 全站文案、版本号、数据口径一致，不出现真实用户信息。

## Assumptions

- 后台源码可读；H5 源码 `exam2.0` 已开通 SSH，按 10 个路由页与源码 SCSS 复刻。
- 原型不接后端、不接微信 SDK、不产生真实文件。
- 浏览器支持 ES2017、Flex/Grid、SVG、Canvas。
- 本地静态服务从仓库根启动，两端相对跳转可用。

## Out of Scope

- 真实登录、支付、短信、微信 JS-SDK。
- 真实导入导出、二维码合成、海报印刷。
- 后台除测评管理外的业务线（保留占位）。
- 像素级 H5 视觉校对（待拿到 `exam2.0` 源码后补）。
