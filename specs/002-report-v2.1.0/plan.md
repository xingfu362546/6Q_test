# Plan: 测评报告页 v2.1.0

## 1. 架构决策

| 决策 | 选项 | 结论 | 理由 |
| --- | --- | --- | --- |
| 版式开关挂在哪 | 商品 / 模板 | **模板** | 测评先配模板、模板再赋给商品；一个模板可复用到多个商品，挂在商品上会重复配置且易不一致 |
| 新版式如何接入 | 新路由 / 同路由分支 | **同路由分支** | 结果页 URL、返回栈、埋点、历史记录跳转全部复用，避免双份维护 |
| 档位数据结构 | 新建 bandList / 复用 results | **复用 results** | 后台已有「测评模板结果」区间表，新建会形成两套区间，运维改一处忘一处 |
| 卡点取值 | 随机 / 固定序 | **固定序** | 随机导致同一答卷结果漂移，无法测试、无法复现、海报会跟着变 |
| 百分比 | 插值 / 档位固定 | **档位固定** | 规格书按档位给值；插值会让 24 分与 47 分显示不同百分比，与文档口径冲突 |
| 文案落点 | 硬编码 / 后台配置 | **后台配置** | 运营改文案不该发版 |
| 海报接入 | 新组件 / 复用 ResultPoster | **复用** | 现网海报是 html2canvas 截 DOM + 模板底图，换风格只需换结构，不需要新依赖 |

## 4. 风险与对策

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| 旧模板被误切新版 | 新版字段全空，页面出现空卡片 | 后端下发默认兜底；前端空值整块隐藏；版式默认 1 |
| 区间被改乱 | 档位判定失效 | 保存校验：从 0 起、连续无重叠、最高档覆盖总分 |
| 题目分值被改 | 60 分制破裂，每维上限不再是 12 | 保存校验：每维分值必须均衡且等于总分 / 维数 |
| 五维商品进「我的测评」 | 原 harmonyDims 写死六维，会显示六个「未点亮」 | 本版一并修：按记录维度动态生成 |
| 旧缓存 | 仍跑旧脚本 | 静态资源版本号升 v4 |
| 动画影响可访问性 | 前庭敏感用户不适 | `prefers-reduced-motion` 下关闭动画 |

## 5. 兼容与回滚

- 接口只增字段，不改既有字段语义，旧客户端忽略新字段即可。
- 回滚方式：把模板 `resultLayout` 改回 1，H5 立即回到旧版式，无需发版。
- 数据回滚：`localStorage` 演示数据可通过后台「重置演示数据」恢复。
