# Feature Spec: 测评报告页 v2.1.0（亲子养育五力）

- 版本：v2.1.0
- 基线：v2.0.0（后台测评管理 9 模块 + H5 十个路由页）
- 上游依据：《6Q亲子养育能力测评_开发交付规格书_v2.4》（2026-11-10 定稿，评审通过）
- 需求来源：需求方 6 张界面截图 + 图 6 的转化闭环文案说明
- 关联 Spec：`specs/001-exam-replica/`（基线，不改动）

## 1. 背景与问题

v2.0.0 的 H5 结果页是通用型：总分 + 维度雷达 / 正态分布 + 整体解读 + 各类详解 + 课程商城 + 星级反馈。
亲子养育测评直接套用这套版式，存在三个问题：

1. 只有维度解读，没有「档位结论」，家长读完不知道自己处在什么位置。
2. 没有核心卡点定位，五维分数并列展示，家长不知道先改哪一个。
3. 没有风险预警与转化承接，报告读完即结束，不产生预约行为。

## 2. 目标

| 编号 | 目标 | 验收口径 |
| --- | --- | --- |
| G1 | 报告给出唯一档位结论 | 同一份答卷反复打开，勋章、金句、超越百分比完全一致 |
| G2 | 明确指出核心卡点 | 取最低分维度；并列时按固定优先序，不随机 |
| G3 | 报告底部有可点击的转化承接 | 底部固定主 CTA，点击弹出导师二维码 |
| G4 | 海报可晒 | 9:16 深绿金，含勋章、金句、背书、二维码 |
| G5 | 旧商品零回归 | v2.0.0 结果页与海报完全不变 |

## 3. 非目标

- 不改动 v2.0.0 的任何结果页逻辑与接口签名。
- 不做真实微信授权头像、不做打卡天数、不做推荐人体系。
- 不做「计分规则」弹窗内容（本轮按钮隐藏，位置预留）。
- 不做班级 / 老师维度的数据看板。

## 4. 用户故事

### US-1 家长查看报告（主链路）

作为完成亲子养育测评的家长，我希望报告直接告诉我「我在哪一档、我最大的卡点是什么、接下来能做什么」，
这样我不需要自己解读五个分数。

验收：结果页（`resultLayout=2`）依次出现 报告头 → 总分与五维雷达 → 档位结论 → 核心卡点 → 风险提示 → 深度了解 → 反馈 → 底部三层 CTA。

### US-2 家长预约解读

作为想深入了解的家长，我希望在报告底部能直接找到人问。

验收：底部主 CTA 带呼吸动画；点击弹出二维码抽屉；关闭后回到报告，不跳页。

### US-3 家长晒朋友圈

作为想分享的家长，我希望有一张能直接发朋友圈的图。

验收：报告头右侧分享入口打开 9:16 海报，含勋章称号、觉醒金句、五维雷达、超越百分比、参与人数、二维码。

### US-4 运营配置报告

作为运营，我希望不写代码就能改档位文案与转化文案。

验收：后台模板新增 / 编辑页可配置版式、档位勋章、金句、百分比、风险提示、转化文案、二维码；保存后 H5 生效。

### US-5 存量商品不受影响

作为负责旧商品的同学，我希望这次改版不动旧报告。

验收：`resultLayout` 缺省为 1，旧商品结果页与海报渲染结果与 v2.0.0 完全一致。

## 6. 计分与档位规则

- 5 个维度 × 每维 4 题 × 每题最高 3 分 = 每维 12 分。
- 总分 60 分。
- 三档：

| 档位 | 区间 | 超越百分比 | 勋章（唯一） | 觉醒金句 |
| --- | --- | --- | --- | --- |
| 低档 | 0–23 | 超越 15% 的家长 | ☀️ 温暖而坚韧的托底妈妈 | 所有的育儿焦虑，都是在等待一个觉醒的自己。 |
| 中档 | 24–47 | 超越 45% 的家长 | 🌱 向光生长的成长妈妈 | 父母的觉醒，是孩子一生的救赎；懂得看见，比一味付出更重要。 |
| 高档 | 48–60 | 超越 95% 的家长 | ✨ 温柔笃定的觉醒妈妈 | 育儿先育己，少一点无谓的控制，多一些静待花开的松弛。 |

- 档位只取一个，不存在并列显示两个勋章。
- 超越百分比按档位固定，报告与海报同一口径，后台可改。

## 7. 核心卡点规则

取五维中得分最低的维度。并列最低时按固定优先序取首个：

情感链接力 → 走心沟通力 → 边界松弛力 → 赋能托底力 → 自我觉察力

不随机、不落库，保证同一份答卷每次渲染结果一致。

## 8. 边界与差异

| 项 | 处理 |
| --- | --- |
| 图 1 的「情感链接 13 分」 | 不采纳。按规格书每维上限 12 分。 |
| 图 1 的旧维度名（沟通模式 / 安全感与尊重 / 信任与认可） | 不采纳。按规格书五力命名。 |
| 图 5 的「超越 78.5%」 | 不采纳。按档位固定值。 |
| 图 4 的两个特质标签 | 不采纳。勋章只显示一个。 |
| 新版式是否保留正态分布 / 6Q 和谐指数 | 不保留。后台按版式分支：新版下这两个开关不出现，维度图固定展示。 |
| 文档 `random.choice` 取卡点 | 不采纳。改固定优先序。 |
| 文档 `PAIN_COPY` 未定义 | 本轮我按场景白描起草五维文案，已标注待需求方确认。 |
| 微信头像 / 打卡天数 / 推荐人 | 占位兜底：本地用户 + 隐藏打卡 + 昵称。 |
| 参与人数三个来源不一致 | 统一取模板虚拟测试人数。 |
| 企业微信活码 | 占位图，后台字段预留。 |

## 9. 验收标准

1. `resultLayout=2` 的商品，结果页出现全部六段区块，顺序与 spec 一致。
2. 同一答卷连续打开三次，勋章、金句、百分比、卡点完全一致。
3. 底部主 CTA 有动画；点击弹二维码；关闭不跳页。
4. 海报为 9:16 深绿金，含勋章、金句、百分比、参与人数、二维码。
5. `resultLayout=1` 的旧商品，结果页与海报与 v2.0.0 一致。
6. 后台模板表单可改三项档位文案与四项转化字段，保存后 H5 生效。
7. 后台校验：档位必须连续覆盖 0–总分；每维分值必须均衡。
8. 全站无断图、无横向滚动、无 JS 报错。
