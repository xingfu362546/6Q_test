## 一分钟结论

- **计分**：5 力 × 20 题，每题选项固定 0/1/2/3 分，每维 12 分，总分 60。
- **档位**：低档 0–23（15%）、中档 24–47（45%）、高档 48–60（95%），每档唯一勋章与金句。
- **核心卡点**：最低分维度；并列按固定优先序，不随机。
- **版式开关**：模板字段 `resultLayout`，1 旧 / 2 新，缺省 1。
- **后台分支**：新版不出现正态分布与 6Q 和谐指数两个开关，维度图固定展示。
- **接口**：只扩字段，不新增接口、不新建表。
- **海报**：深绿金 9:16，导出 810×1440；雷达按每维上限还原得分并标注。
- **扫码进入**：`price = 0` 自动建单后直进测评；`price > 0` 进商品详情。
- **推荐关系**：`ref` 落库、首次优先、订单带 `referrer`。
- **登录**：未登录先登录再回跳；H5 与 APP 内嵌一律要求登录。
- **欣赏**：v2.2 新增「这些力，值得欣赏」；v2.2.1 起**只展示 1 条**（非卡点维度分数最高者，同分取索引更小），不展示小建议。
- **报告顺序**：总分与档位 → 核心卡点 → 孩子正在经历什么 → 这些力值得欣赏 → 深度了解与 CTA。
- **固定数据**：`record=demo-low / demo-mid / demo-high` 复现三档报告。
