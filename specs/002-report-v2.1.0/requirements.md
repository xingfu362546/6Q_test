## 1. EX-051 · 结果页版式开关（后台）

**改动前**：结果页版式由四个展示开关（总分 / 维度图 / 正态分布 / 6Q 和谐指数）隐式决定，没有独立版式概念。亲子养育测评只能套通用结果页。

**改动后逻辑**

1. 模板新增字段 `resultLayout`：`1` 旧版、`2` 新版；缺省按 `1`。
2. 版式挂在**模板**上；模板赋给商品，H5 按商品关联模板读取，不在商品上重复配置。
3. 选新版后，「报告结果设置」页按版式分支渲染：
   - 开关组只保留「是否展示总分」；
   - 「维度图表展示」固定为「是」，置灰并标「新版固定」；
   - **正态分布图表展示、6Q 和谐指数展示两行整行移除**。
4. 切版式自动联动：维度图 = 是、正态分布 = 否、和谐指数 = 否。
5. 切回旧版恢复四个开关与旧表头，已存的档位字段不丢。
6. H5 新版式不再读取正态分布与和谐指数两个开关，即使历史数据为 `true` 也不渲染。

**接口改动**

| 接口 | 改动 |
| --- | --- |
| `GET exam/exam/templete/detail` | 响应新增 `resultLayout` |
| `POST exam/exam/templete/create` | 请求新增 `resultLayout` |
| `PUT exam/exam/templete/modify` | 请求新增 `resultLayout` |
| `GET /exam/app/api/viewCheckResult` | 响应 `templete.resultLayout` |

缺失字段按 `1` 处理，旧模板零改动。

**验收**：新版模板下 ③ 页只剩总分 + 维度图（置灰）；旧版模板下四个开关齐全；切版式后表头同步切换。

## 2. EX-052 · 新风控与转化文案（后台）

**改动前**：解读全部来自结果区间表与维度解读表，没有「风险提示」「转化文案」概念，也没有导师二维码。

**改动后逻辑**

1. 档位表**复用现有「测评模板结果」**，不新建表；新增 `badge` / `quote` / `percentile` 三列。
2. 新增四个模板文本字段：`riskTip`、`ctaText`、`ctaSubText`、`ctaQrCode`。
3. 四个字段只在新版渲染；留空时 H5 整块隐藏，不出空卡片。
4. 保存校验：
   - 档位必须从 `0` 开始；
   - 相邻档位 `min = 上一档 max + 1`，不允许空档或重叠；
   - 最高档 `max` 必须等于测评总分；
   - 每维题目最高分之和必须等于「总分 ÷ 维数」。
5. 校验不通过只提示并阻止保存，不写脏数据。

**接口改动**

| 接口 | 改动 |
| --- | --- |
| `GET exam/exam/templete/detail` | 响应新增四个字段 + `results[].badge/quote/percentile` |
| `POST create` / `PUT modify` | 请求新增同名字段 |
| `GET /exam/app/api/viewCheckResult` | 响应 `templete.*` 下发 |

不新增接口、不新建表。

**验收**：改低档上限为 20 后保存 → 提示档位有空档；改某选项分值为 5 后保存 → 提示最高档未覆盖总分。

## 4. EX-202 · 档位结论与超越百分比（H5）

**改动前**：总分 + 雷达 / 正态分布 + 整体解读，没有档位、勋章、超越百分比。

**改动后逻辑**

1. 按总分命中三档：低档 `0–23`、中档 `24–47`、高档 `48–60`。
2. 每档唯一勋章与金句，只取一个，不并列、不显示两个特质标签。
3. 超越百分比按档位固定 `15% / 45% / 95%`，报告与海报同口径，后台可改。
4. 五维雷达在维度名下方标该维得分；得分由 `scoreList[]` 的 `score / maxScore` 还原，每维上限 12。
5. 维度顺序按后台维度模板配置，不在前端写死。
6. `showTotalScore = false` 时隐藏总分，其余结构不变。

**接口**：`results[]` 需含 `badge` / `quote` / `percentile`（与 EX-052 同一批字段）；`scoreList[]` 需含 `maxScore`。

**UI**：五维雷达（带分数）、档位结论版式。

**跳转**：三档各一份固定数据，见第 9 节。

## 10. EX-207 · 海报雷达图的取数规则（H5）

**改动前**：海报雷达按维度百分比直接画，没还原原始得分，海报上也不显示每维分数。

**改动后逻辑**

1. 取该次记录的 `dims`（五维，`value` 为百分比）。
2. 每维上限 `maxPer = round(记录总分 ÷ 维数)`，五力即 12。
3. 还原原始得分 `raw = round(value ÷ 100 × maxPer)`。
4. 按 `raw ÷ maxPer` 归一化画点，维度名下方标 `(raw分)`。
5. 无记录时（详情页分享）用各维 8 分示意值，不谎报成绩。
6. 报告与海报同数据源，同一答卷两处一致。

**接口**：`viewCheckResult` 的 `scoreList[]` 提供 `name` / `score` / `maxScore`，不新增。

**UI**：海报雷达带分数标注。

**跳转**：`result.html?record=demo-mid&goodsId=g-parent&note=EX-207`

## 11. EX-208 · 扫码进入的分流与免费无感建单（H5）

**改动前**：海报只指详情页；测评必须先下单再从订单点测试，免费测评也要走四步。

6. 落地页显示「校验登录 → 开通订单 → 进入测评」三段状态。

**接口**：`exam/order/create`（免费单，金额 0，新增 `channel=scan_free`）；`exam/exam/templete/detail`。

## 13. EX-210 · 扫码进入的登录校验（H5）

**改动前**：登录后固定返回上一页，没有扫码场景拦截，也无法把用户送回原目标。

**改动后逻辑**

1. 落地页先判登录态（`exam_session.token`），未登录跳登录页。
2. 登录页支持 `redirect`，成功后回落地页继续。
3. 跳登录前先存推荐关系与目标商品，参数不丢。
4. **H5 与 APP 内嵌一律要求登录**，不因环境跳过。
5. 登录成功后才建单与进测评，未登录不产生订单。
6. 已登录用户直接进分支。

详细流程与边界见 [share-entry.md](share-entry.md)。

**接口**：`/security/api/user/login`、`/security/api/user/info`（既有）。

**UI**：登录拦截页与回跳。

**跳转**：`entry.html?goodsId=g-free&ref=S6MULM1&note=EX-210`（清掉 `exam_session` 即为未登录态）

3. **只展示 1 条**：取候选里分数最高的维度，不展示多条。
4. **同分取索引更小**（维度配置顺序靠前）的那个，保证结果唯一且可复现。
5. 该维度分数低于 8 分（每维满分 × 2/3）时，文案改用「相对优势版」，保证人人都有 1 条；
   8 分只用于判断措辞，不参与「取哪一条」。
6. 核心卡点维度永不出现在欣赏列表。
7. **不展示小建议**（v2.2.1 移除）。
8. **版块顺序：核心卡点 → 孩子正在经历什么 → 这些力值得欣赏**。
   规格书 v2.2 原稿把欣赏插在卡点与风险之间；按需求方本轮口径改为先卡点与风险、后欣赏。
9. 卡点与风险同样只展示一条：卡点取最低分维度、风险取同一维度，**分数相同时取索引更小的**。

**接口**：`viewCheckResult` 的 `weiduExplainList[]` 携带四段文案，不新增接口。

**UI**：暖金底卡片、维度标题 `【维度名】（X 分）`，单条展示，无小建议行。
