## 1. EX-051 · 结果页版式开关（后台）

**改动前**：结果页版式由四个展示开关（总分 / 维度图 / 正态分布 / 6Q 和谐指数）隐式决定，没有独立版式概念。亲子养育测评只能套通用结果页。

**改动后逻辑**

1. 模板新增字段 `resultLayout`：`1` 旧版、`2` 新版；缺省按 `1`。
2. 版式挂在**模板**上；模板赋给商品，H5 按商品关联模板读取，不在商品上重复配置。
3. 选新版后，「报告结果设置」页按版式分支渲染：
   - 开关组只保留「是否展示总分」；
   - 「维度图表展示」固定为「是」，置灰并标「新版固定」；
   - **正态分布图表展示、6Q 和谐指数展示两行整行移除**。
4. 切版式自动联动：维度图 = 是、正态分布 = 否、和谐指数 = 否。
5. 切回旧版恢复四个开关与旧表头，已存的档位字段不丢。
6. H5 新版式不再读取正态分布与和谐指数两个开关，即使历史数据为 `true` 也不渲染。

**接口改动**

| 接口 | 改动 |
| --- | --- |
| `GET exam/exam/templete/detail` | 响应新增 `resultLayout` |
| `POST exam/exam/templete/create` | 请求新增 `resultLayout` |
| `PUT exam/exam/templete/modify` | 请求新增 `resultLayout` |
| `GET /exam/app/api/viewCheckResult` | 响应 `templete.resultLayout` |

缺失字段按 `1` 处理，旧模板零改动。

**验收**：新版模板下 ③ 页只剩总分 + 维度图（置灰）；旧版模板下四个开关齐全；切版式后表头同步切换。

## 2. EX-052 · 新风控与转化文案（后台）

**改动前**：解读全部来自结果区间表与维度解读表，没有「风险提示」「转化文案」概念，也没有班主任二维码。

**改动后逻辑**

1. 档位表**复用现有「测评模板结果」**，不新建表；新增 `badge` / `quote` / `percentile` 三列。
2. 新增四个模板文本字段：`riskTip`、`ctaText`、`ctaSubText`、`ctaQrCode`。
3. 四个字段只在新版渲染；留空时 H5 整块隐藏，不出空卡片。
4. 保存校验：
   - 档位必须从 `0` 开始；
   - 相邻档位 `min = 上一档 max + 1`，不允许空档或重叠；
   - 最高档 `max` 必须等于测评总分；
   - 每维题目最高分之和必须等于「总分 ÷ 维数」。
5. 校验不通过只提示并阻止保存，不写脏数据。

**接口改动**

| 接口 | 改动 |
| --- | --- |
| `GET exam/exam/templete/detail` | 响应新增四个字段 + `results[].badge/quote/percentile` |
| `POST create` / `PUT modify` | 请求新增同名字段 |
| `GET /exam/app/api/viewCheckResult` | 响应 `templete.*` 下发 |

不新增接口、不新建表。

**验收**：改低档上限为 20 后保存 → 提示档位有空档；改某选项分值为 5 后保存 → 提示最高档未覆盖总分。

## 3. EX-201 · 报告头与测评日期（H5）

**改动前**：顶部只有返回与「测评结果」标题，没有报告头与测评日期。

**改动后逻辑**

1. 顶部新增报告头：大标题「测评报告」+ 测评日期。
2. 日期取记录 `createTime`，格式 `YYYY-MM-DD HH:mm:ss`，不在前端重算。
3. 分享入口保留在报告头右侧，打开觉醒海报（EX-206）。
4. 「计分规则」按钮本轮隐藏，位置与类名预留。

**接口**：读取既有 `check.createTime`，无需新增字段。

**UI**：报告头排版、标题字重与配色。

**跳转**：`result.html?record=demo-mid&goodsId=g-parent&note=EX-201`

## 4. EX-202 · 档位结论与超越百分比（H5）

**改动前**：总分 + 雷达 / 正态分布 + 整体解读，没有档位、勋章、超越百分比。

**改动后逻辑**

1. 按总分命中三档：低档 `0–23`、中档 `24–47`、高档 `48–60`。
2. 每档唯一勋章与金句，只取一个，不并列、不显示两个特质标签。
3. 超越百分比按档位固定 `15% / 45% / 95%`，报告与海报同口径，后台可改。
4. 五维雷达在维度名下方标该维得分；得分由 `scoreList[]` 的 `score / maxScore` 还原，每维上限 12。
5. 维度顺序按后台维度模板配置，不在前端写死。
6. `showTotalScore = false` 时隐藏总分，其余结构不变。

**接口**：`results[]` 需含 `badge` / `quote` / `percentile`（与 EX-052 同一批字段）；`scoreList[]` 需含 `maxScore`。

**UI**：五维雷达（带分数）、档位结论版式。

**跳转**：三档各一份固定数据，见第 9 节。

## 5. EX-203 · 核心卡点（H5）

**改动前**：只按维度列 `detail` 与 `suggest`，没有最低分维度定位。

**改动后逻辑**

1. 取五维中得分最低的维度。
2. 并列最低时按**固定优先序**取首个：情感链接力 → 走心沟通力 → 边界松弛力 → 赋能托底力 → 自我觉察力。
3. 不随机、不落库；同一份答卷反复打开结果一致。
4. 文案取该维 `weiduExplainList[].detail`，留空整块隐藏。

**接口**：用既有 `scoreList` + `weiduExplainList`，无需新增字段。

**UI**：粉红渐变卡、长文案排版。

**跳转**：`demo-mid`（卡点情感链接力）、`demo-low`（卡点边界松弛力）。

## 7. EX-205 · 深度了解与底部预约 CTA（H5）

**改动前**：底部是结果页反馈 + 课程商城双 Tab，没有固定 CTA，也没有二维码入口。

**改动后逻辑**

1. 底部三层：呼吸动画主 CTA「预约班主任 1 对 1 解读」→ 弹二维码抽屉；下方保留「查看历史测试记录 / 再答一次」。
2. 动画只用 CSS：呼吸缩放 + 光晕 + 箭头位移；`prefers-reduced-motion` 下关闭。
3. 二维码抽屉点遮罩或关闭可收起，不跳页。
4. 课程商城并入「深度了解」卡，不再单开 Tab。
5. 深度了解文案取 `ctaText`，为空整卡隐藏；二维码取 `ctaQrCode`，为空用占位图。
6. 新版式不再调用正态分布接口 `getZtfbScore`。

**接口**

| 接口 | 改动 |
| --- | --- |
| `GET /exam/app/api/viewCheckResult` | 读取 `templete.ctaText / ctaSubText / ctaQrCode` |
| `POST /exam/app/api/listGoodsInfoByTypeAndIds` | 既有，精选课程 |
| `GET /exam/app/api/getZtfbScore` | 新版**不再调用** |

**UI**：底部三层布局、呼吸动效、二维码抽屉。

**跳转**：`result.html?record=demo-mid&goodsId=g-parent&note=EX-205`

## 8. EX-206 · 觉醒海报（H5）

**改动前**：`550×956` 深蓝渐变，只有标题、总分、雷达与通用二维码。

**改动后逻辑**

1. 改深绿金 9:16，导出 `810×1440`。
2. 元素：勋章称号（唯一）、觉醒金句、金色五维雷达、超越百分比、参与人数背书、带参二维码。

6. 真实环境二维码走 `createShare`，不新增接口。

**接口**：`POST /security/api/user/share/center/createShare`（既有）；勋章 / 金句 / 百分比来自 `viewCheckResult`。

## 9. 固定模拟数据

结果报告页通过 `record` 参数复现固定报告；答案、测评日期、订单号均写死，不读写 `localStorage`。

| record | 总分 | 档位 | 超越 | 核心卡点 | 测评日期 | 答案规律 |
| --- | --- | --- | --- | --- | --- | --- |
| `demo-low` | 16 | 低档 | 15% | 边界松弛力 | 2026-11-05 10:24:08 | 五维选项压到 0–1 分（P1:1 / P2:1 / P3:0 / P4:1 / P5:1） |
| `demo-mid` | 40 | 中档 | 45% | 情感链接力 | 2026-11-03 17:13:32 | 五维全选第 3 个选项（各 8 分，并列按优先序取首个） |
| `demo-high` | 56 | 高档 | 95% | 边界松弛力 | 2026-11-07 21:40:15 | 五维高位、边界略低（P1:3 / P2:3 / P3:2 / P4:3 / P5:3） |

`record=demo` 或不传 `record` 时按 `demo-mid` 处理。
`demo-*` 一律不写入 `exam_records`，刷新结果不变。
