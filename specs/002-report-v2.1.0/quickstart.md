# Quickstart: 测评报告页 v2.1.0

## 1. 启动

```bash
cd D:/Cursor/6Q_test
python -m http.server 8766
```

## 2. 看新版结果页（3 步）

1. 打开 `http://localhost:8766/6Q_exam_h5/quiz.html?goodsId=g-parent`
2. 连续点任意选项，到第 20 题后点「提交」
3. 自动跳 `result.html`，看到新版报告

一次看完的主要区块：

| 区块 | 位置 |
| --- | --- |
| 报告头 + 测评日期 | 顶部 |
| 总分 + 五维雷达 | 「测评结果」卡 |
| 档位结论 + 超越百分比 | 同卡下方 |
| 核心卡点 | 粉红渐变卡 |
| 孩子正在经历什么 | 白卡 |
| 深度了解 + 精选课程 | 白卡 |
| 星级反馈 | 白卡 |
| 底部三层 CTA | 固定在底部 |

## 3. 看底部 CTA 与二维码

1. 滚到报告底部
2. 观察「预约班主任 1 对 1 解读」的呼吸动画（缩放 + 光晕 + 箭头位移）
3. 点击 → 底部弹出二维码抽屉
4. 点「关闭」或点遮罩 → 回到报告，不跳页

## 4. 看海报

报告头右侧分享图标 → 弹出深绿金 9:16 海报：
勋章称号 + 觉醒金句 + 金色五维雷达 + 超越百分比 + 参与人数 + 二维码。

点「点击保存至相册」会导出 `810×1440` PNG。

应看到旧版：总分 + 雷达 / 正态分布切换 + 各类详解 + 课程商城 + 星级反馈，底部没有三层 CTA。

## 6. 后台配置

| 要改什么 | 路径 |
| --- | --- |
| 切版式 | `replica.html?p=template-form&id=tpl-parent` → ① 基础信息 → 报告版式 |
| 改档位勋章 / 金句 / 百分比 | 同页 → ③ 报告结果设置 → 测评模板结果表 |
| 改风险提示 / 转化文案 / 二维码 | 同页 → ③ 报告结果设置 → 新风控与转化文案 |
| 查看配置结果 | `replica.html?p=template-detail&id=tpl-parent&tab=report` |

保存时若档位有空档、重叠或未覆盖满分，会弹出提示并阻止保存。

## 8. 常见问题

**结果页还是旧版？**
商品的模板 `resultLayout` 不是 2。改模板配置，或把 `localStorage.exam_admin_data` 清掉后重进。

**档位改完不生效？**
H5 读的是记录里的 `rangeName` 对应档位，改档位文案后需要刷新；改区间会影响命中，需要重新答题。

**二维码是占位的？**
原型不接企业微信，`ctaQrCode` 填的是占位图；真实环境由后端下发图片地址。

**动画不动？**
系统开启了「减少动态效果」，`prefers-reduced-motion` 下动画按设计关闭。
